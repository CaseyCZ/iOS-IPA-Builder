Two build modes

Use the same workflow for sideloading builds or a normal Apple distribution build.

01

Unsigned IPA

Creates a clean Release build with code signing disabled, then packages the app as a standard IPA for signing elsewhere.

02

App Store / TestFlight

Uses your own Apple Distribution certificate and provisioning profile to create a signed IPA. Upload to Apple stays manual.

How it works

The builder is a GitHub workflow, not a desktop app. GitHub starts a macOS runner and does the build remotely.

STEP 1Select sourceChoose repository, branch or tag.
STEP 2Detect projectXcode, Capacitor, Flutter or React Native.
STEP 3Build on macOSXcode creates the unsigned or signed IPA.
STEP 4Deliver releaseSave the IPA to a public or private GitHub Release.

Supported projects

Auto detection is the default, with manual override available when needed.

Native Xcode Capacitor Flutter React Native
Standard GitHub-hosted runners only. No larger runner configuration, no Actions artifact storage, and no automatic App Store Connect upload.
